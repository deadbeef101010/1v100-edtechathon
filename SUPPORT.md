# Support

Community support is available through GitHub Issues for reproducible bugs, installation problems, and focused feature requests. Include the released version, operating system, Docker version, relevant redacted logs, and steps to reproduce with synthetic data.

This is a volunteer open-source project. It does not provide emergency, classroom-time, privacy-compliance, hosting, or uptime support, and there is no response-time SLA. Do not post credentials, student data, session codes, private hostnames, or database files in an issue.

For suspected vulnerabilities, follow [`SECURITY.md`](SECURITY.md) instead of opening a public issue.

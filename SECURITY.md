# Security policy

## Supported version

Security fixes are provided on a best-effort basis for the latest released version. This project has no formal support or response-time SLA.

## Report a vulnerability

Please use the repository's private **Report a vulnerability** form under the Security tab. Do not open a public issue for an unpatched vulnerability and do not include real classroom data, production keys, access tokens, or exploit traffic containing student information.

Include the affected version, impact, reproduction steps using synthetic data, and any suggested mitigation. Maintainers will acknowledge the report when available, investigate, and coordinate disclosure after a fix or mitigation is ready.

For ordinary bugs and hardening ideas that do not expose users or data, use the public issue tracker.
